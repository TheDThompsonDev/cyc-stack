# Verify

Use to establish whether existing work meets its criteria. Stages: [scout](../../../../methods/cyc-scout/SKILL.md) → [verify](../../../../methods/cyc-verify/SKILL.md) → [deliver](../../../../methods/cyc-deliver/SKILL.md).

In the scout pass, list each criterion and the consumers the work affects, and find or write a check that would fail if each were broken. Run the configured checks and the [verify recipe](../../../../methods/cyc-verify/references/recipe.md). A failed criterion is reported, not quietly fixed, unless fixing is in scope.

**Acceptance:** every criterion reported as passed, failed, or unverified, each with its evidence.
