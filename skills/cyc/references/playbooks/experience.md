# Experience

Use to improve a whole user journey, not one component. Stages: [scout](../../../../methods/cyc-scout/SKILL.md) → [explore](../../../../methods/cyc-explore/SKILL.md) → [build](../../../../methods/cyc-build/SKILL.md) → [verify](../../../../methods/cyc-verify/SKILL.md) → [deliver](../../../../methods/cyc-deliver/SKILL.md).

In the scout pass, walk the current journey end to end and find every screen and state it touches. Explore two or three genuinely different approaches, prototyping on the real page when the answer is visual, and recommend one. Build it so the whole journey holds together, not just the changed step. Verify in the real app with the [verify recipe](../../../../methods/cyc-verify/references/recipe.md) (journey, console, layout shift, accessibility) as well as the configured checks.

**Acceptance:** the full journey works in the real app, the recipe observations are recorded, and every configured check passes. A step that could not be exercised in a real browser is reported as unverified, not passed.
