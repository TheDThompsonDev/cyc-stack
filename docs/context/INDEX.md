# CYC project context

Read this index first, then only the docs whose Covers match the paths you are about to change, and the error ledger for that area. Each component row says when AI last changed the doc, from which run, and how many lessons it holds, so the match can be judged here without opening every doc. `cyc investigate --path ...` does the matching; `cyc context lint` checks these rows against the docs and against Git; `cyc context review` proposes the next entries from completed runs.

This is context for developing the CYC source checkout. An installed application uses its own project context; the engine's copied documentation is not that application's component map.

Component docs live in this folder in the layout the Context method fixes (Covers, Last changed by AI, Current view, Lessons, History). Reference rows point to maintained documentation elsewhere; they are matched like component rows but `cyc context review` does not write to them.
