## Current view

scripts/onboarding.mjs:onboardProject inspects installation, configured checks, diagnostic receipts and actual current-host evidence. Its environment metadata describes the executing CLI's Node/OS/architecture, not the host application's version. inspectHostActivation owns request/response and implementation/configuration/declaration binding. Passing local commands never imply native activation. A current prompt can permit the authorized task while its own Stop remains pending. Missing trust, absent tokens, stale or rejected observations remain explicit; Cursor correlation and unsupported hosts stay unverified. Host versions must be separately observed. Local trace files are editable observations, not independent certification.

scripts/recovery.mjs projects additive guidance from authoritative results. CLI finish/wait distinguish active work, missing context/proof judgment, failed checks, delivery publication and recorded completion. A passed check or finished worker cannot imply workflow completion. Existing raw fields, receipts and run IDs remain available. Native gates are unchanged; standalone delivery cannot certify activation or product readiness.

Cursor deliberately requires a separate exact-response packet after work is recorded. Guidance uses the owned execution mode and this existing producer result to retain needs-input and the packet instruction; it does not describe the expected step as publication failure. Real publication errors still need repair. The first fresh review exposed this compatibility issue and a missing-owner History bypass; focused regressions retain both demonstrated failures and their guards.

recoverRun reads existing state, source constraints and historical receipts without writing. recoveryGuidance supplies the exact owned resume command only for an actually resumable paused run; continuing/check-needed work points to read-only run next. Blocked, terminal, conflicting and stale evidence requires inspection and has no automatic mutation command. Budgets, ownership, source preservation and original criteria remain controller-owned. Recorded completion is historical when later source differs.
