Covers: evals/cohort-journey/**, evals/README.md, test/cohort-evaluation.test.mjs

## Current view

The source-only cohort-journey exercise prepares isolated first, related and interrupted-task observations. candidate/src/tasks.mjs is a deliberately incomplete Open tasks view. request.md defines exact-false membership, record/input preservation and fresh-chat count consistency. evaluate.mjs executes named behavior assertions, compares full records including imported/permission/extra fields and distinguishes module loading from behavioral failures. It preserves independent probe baselines across rejected operations. Its selected entrypoint hash excludes dependencies; use a fresh CLI invocation and externally bind the full task snapshot.

The report is behavior_probe_not_user_trial with actual per-check outcomes and explicit scope limits. It cannot certify context reading, host activation, interruption recovery, participant understanding or lower effort. The public fixture and its broken/coherent controls are known development evidence, not held-out evaluation. Tests catch dropped fields, competing membership and rejected-view mutation.

protocol.md reuses live-session-reuse.md: proposed six-person first/related/interrupted journeys, actual prompts/versions/evidence, observer/agent/user provenance, assistance and null unknown usage. No participants were recruited, no trial was run, and no host callback or pilot result is generated by these files. Keep evaluator material separate from disposable producer copies and sensitive transcripts outside distribution; original benchmarks remain frozen.
